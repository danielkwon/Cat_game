# 🐾 냥냥 키우기

브라우저에서 바로 즐기는 고양이 키우기 게임입니다. 설치할 것 없이 `index.html`을 열면 시작돼요.

## 플레이 방법

1. 고양이 이름과 털 색깔을 고르고 **입양하기**를 누릅니다.
2. 시간이 지나면 포만감·행복·에너지·청결이 조금씩 줄어들어요. 버튼으로 돌봐주세요.

| 행동 | 효과 |
| --- | --- |
| 🍗 밥주기 | 포만감 ↑ |
| 🧶 놀아주기 | 행복 ↑, 에너지 ↓, 코인 +3 |
| 🤚 쓰다듬기 (고양이 클릭도 가능) | 행복 ↑, 코인 +1 |
| 💤 재우기 / 깨우기 | 자는 동안 에너지 회복 |
| 🛁 씻기기 | 청결 100, 대신 살짝 삐짐 |
| 🐟 생선잡기 | 10초 미니게임, 잡은 만큼 코인 획득 |
| 🛒 상점 | 참치캔·츄르·캣닢·영양제 구매 후 선물 |
| 🏥 병원 | 코인 15개로 건강 회복 |

- 포만감·청결·행복이 너무 낮으면 **건강**이 나빠져요.
- 돌봐줄수록 경험치가 쌓여 **아기 → 꼬마 → 어른 → 대장 고양이**로 성장합니다.
- 진행 상황은 브라우저(localStorage)에 자동 저장되고, 게임을 끈 동안에도 시간이 (5배 느리게) 흘러요.

## 파일 구성

- `index.html` – 화면 구조
- `style.css` – 스타일과 애니메이션
- `game.js` – 게임 로직 (스탯, 행동, 상점, 미니게임, SVG 고양이 그리기, 저장)
